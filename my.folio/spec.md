# Portfolio Website Spec

## What
- เว็บไซต์ Portfolio นักเรียน ม.3 สายวิทย์-คณิต
- ใช้สำหรับยื่นประกอบการสัมภาษณ์เข้าศึกษาต่อ ม.4

## Who
- กลุ่มผู้ใช้: ครูแนะแนว และคณะกรรมการสัมภาษณ์
- อ่านผ่านมือถือหรือแท็บเล็ต
- ต้องการข้อมูลสำคัญภายใน 1-2 นาที

## Why
- นำเสนอผลงานในรูปแบบดิจิทัล
- เข้าถึงง่ายผ่าน QR Code หรือ Link
- แสดงทักษะด้าน Digital Literacy
- ขจัดข้อจำกัดของกระดาษ

## Features
1. Hero Section: รูปภาพนักเรียน, ชื่อ-นามสกุล, สายการเรียน, Catchphrase
2. About & Education: ประวัติสั้น, คติประจำใจ, เกรดเฉลี่ย
3. Skills: ทักษะวิชาการ, Soft Skills, progress bar
4. Awards & Projects: Gallery card 4 ชิ้น พร้อมคำอธิบายสั้น
5. Activities: ภาพถ่ายกิจกรรมหรือจิตอาสา
6. Contact: อีเมล, เบอร์โทรศัพท์, สายการเรียน, ลิงก์เพิ่มเติม

## Look
- โทนสี: ขาว-ฟ้าดูวิชาการ
- สไตล์: Modern, Clean, Minimal
- Responsive design รองรับมือถือ/แท็บเล็ต/เดสก์ท็อป
- ไม่มี animation ที่วิบวับหรือโหลดช้า

## How
- ใช้ HTML + CSS
- เนื้อหาสั้น กระชับ เป็นจุดๆ
- วางเป็นหน้าเดียว (single page)
- เน้นโหลดเร็ว และอ่านง่าย
